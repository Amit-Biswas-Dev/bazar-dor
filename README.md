
# বাজার দর | BazarDor

A simple and user-friendly web application that helps people in Bangladesh explore the latest prices of essential daily products. বাজার দর makes it easier to compare prices and understand daily market price changes in one place.

## Technologies Used

- **Next.js** — React framework for the web application
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Utility-first styling
- **DaisyUI** — UI components and theme styling
- **Better Auth** — Authentication and user profile management
- **MongoDB** — Database for authentication and user data
- **BazarDor API** — Product, category, and market price data

## Key Features

1. **Product Categories** — Browse essential products by category.
2. **Daily Price Comparison** — View today's prices alongside yesterday's prices.
3. **Price Change Indicators** — Easily identify products whose prices have increased or decreased.
4. **Price Sorting** — Sort products from lowest to highest price or highest to lowest price.
5. **User Authentication & Profile** — Sign in with email and password or Google, view your profile, and update your name.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Amit-Biswas-Dev/bazar-dor.git
cd bazar-dor
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file in the project root and configure the required variables for Better Auth, MongoDB, and Google OAuth.

Never commit secrets, passwords, or private API credentials to GitHub.

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
